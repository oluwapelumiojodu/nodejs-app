# Node.js & Docker Deployment

## Project Description
A simple Node.js application deployed using GitHub, Linux (AWS EC2), Docker, and Docker Hub.

## Docker Image
Docker Hub: `oluwapelumiojodu/nodejs-app:1.0`

## Deployment
The application was:
- Built as a Docker image
- Pushed to Docker Hub
- Pulled onto an AWS Ubuntu EC2 server
- Run in a Docker container on port 3000
